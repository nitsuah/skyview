Features

What you get

Every screenshot below is regenerated by CI from mocked demo data whenever the UI changes, and the short videos are cut from those same screens. Click any image to expand it.

Core experiences

The marketing site: a full-screen hero, service packages, and a gallery, in plain HTML, CSS and ES modules.

Marketing & personalization

Runs in the browser, with no third-party tracker.

Campaign personalization

UTM parameters and the referrer pick a per-source hero subline, kept for the session.

A/B testing framework

Deterministic per-visitor buckets for hero headline and CTA experiments. Off by default in config.js.

Conversion funnel tracking

Landing, gallery, and booking events with referrer and campaign metadata, stored locally.

Funnel reporting

An owner-only dashboard on top of the funnel events, with CSV and JSON export.

Admin & CMS

The owner edits the gallery without touching code.

Client portal

Clients open their delivery with a signed, expiring access code that is verified server-side with HMAC-SHA256.

Marketplace platform

The marketing site is the front door. Every booking CTA drops into the platform app at /app, where clients post jobs and FAA Part 107-certified operators accept them.

Security & infrastructure

A zero-build static site in front, a React + Vite app on Netlify Functions behind it.

Hardened by default

CSP and Permissions-Policy on every page, no-store portal and gallery routes, and a daily FAA certificate-expiry cron.

No build step up front

The marketing site is plain ES modules. Only the /app SPA has a Vite build.

Docker parity

The Docker image runs the same build as Netlify, and the unit suite runs in a container.
