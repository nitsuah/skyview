Under the hood

No build step up front

A zero-build static marketing site in plain ES modules, with a React + Vite platform behind it on Netlify Functions.

Two-sided marketplace

Clients post jobs; operators onboard, list services and rates, and accept bookings. Stripe Connect handles payouts.

Native scheduling

Weekly hours plus blocked dates per operator, enforced by checkOperatorAvailability() and a DB constraint. Calendly is gone.

Campaign personalization

UTM and referrer detection swap the hero subline per source. A deterministic A/B framework is ready to switch on.

Privacy-first funnel

Landing → gallery → booking tracking with an owner-only dashboard and CSV/JSON export.

Signed client portal

HMAC-SHA256 access codes verified server-side. The endpoint fails closed if PORTAL_SALT is unset.

Hardened by default

CSP and Permissions-Policy on every page, a no-index, no-store admin, and a daily FAA certificate-expiry cron.
